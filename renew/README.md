# تمدید خودکار KataBump — MeowRay Renew v2

سرور رایگان KataBump هر **۴ روز** باید تمدید شود؛ وگرنه سرور متوقف/حذف می‌شود.
این پوشه یک ربات تمدید خودکار است که روی **GitHub Actions** اجرا می‌شود و هر
**۲ روز** یک‌بار (حاشیهٔ امن دوبرابری) روی دکمهٔ Renew سرور شما کلیک می‌کند.

> این فایل‌ها جدا از دو فایل اصلی پنل (`index.js` + `package.json`) هستند و
> روی خود سرور آپلود نمی‌شوند؛ فقط داخل یک ریپوی گیت‌هاب قرار می‌گیرند.

## نصب (۵ دقیقه)

۱. یک ریپوی گیت‌هاب بسازید (خصوصی بهتر است).
۲. فایل `renew.py` را در **ریشهٔ (Root)** ریپو بگذارید.
۳. فایل `renew.yml` را در مسیر `.github/workflows/renew.yml` بگذارید.
۴. در ریپو بروید به **Settings → Secrets and variables → Actions** و با
   **New repository secret** این سه سکرت را اضافه کنید:

| Secret | مقدار |
| :--- | :--- |
| `KATABUMP_EMAIL` | ایمیل حساب KataBump |
| `KATABUMP_PASSWORD` | رمز عبور حساب KataBump |
| `SERVER_ID` | شناسهٔ سرور — وقتی صفحهٔ سرورتان را در داشبورد KataBump باز می‌کنید، در آدرس صفحه (URL) دیده می‌شود |

۵. از تب **Actions** یک‌بار **Run workflow** بزنید تا همان اول مطمئن شوید
   درست کار می‌کند؛ بعد از آن خودش هر ۲ روز اجرا می‌شود.

## تفاوت با نسخهٔ MF Panel (چرا v2؟)

- **هیچ شناسهٔ سرور هاردکدشده‌ای وجود ندارد.** نسخهٔ MF اگر `SERVER_ID` تنظیم
  نشده بود، به یک شناسهٔ پیش‌فرض ثابت برمی‌گشت — یعنی یا سرور کس دیگری تمدید
  می‌شد یا تمدید بی‌صدا از کار می‌افتاد. در v2 نبودن هر سکرت = توقف فوری با
  خطای واضح (exit 2).
- **موفقیت با مدرک صفحه ثابت می‌شود** (متن تمدید/انقضا یا وضعیت دکمه)، نه با
  فرضِ «کلیک شد پس شد».
- **در صورت خطا، اسکرین‌شات + HTML صفحه** به‌صورت Artifact همان اجرا در
  GitHub Actions ذخیره می‌شود تا دقیقاً ببینید ربات چه دیده است
  (Actions → همان اجرا → Artifacts → `renew-failure-…`).

## عیب‌یابی

- **خطای «missing required secrets»:** یکی از سه سکرت ست نشده یا اسمش غلط است.
- **خطای «login did not complete»:** ایمیل/رمز اشتباه است یا KataBump کپچا
  گذاشته است؛ اسکرین‌شات Artifact را ببینید.
- **خطای «renew button not found»:** ساختار داشبورد KataBump عوض شده است؛
  اسکرین‌شات را ببینید و سلکتورهای `renew.py` را با صفحهٔ جدید تطبیق دهید
  (بخش «find and click Renew»). یک‌بار تمدید دستی هم مشکل فوری را حل می‌کند.
